Features

— 主な機能 —

日付フォルダへ即時移動

ファイルを移動タイルにドロップするだけで、自動的に今日の日付フォルダへ整理。手作業のリネーム・移動が不要になります。

ファイル・フォルダ ショートカット

よく開くフォルダやファイルのパスをリンクタイルとして登録。クリック一発でエクスプローラーが開きます。

アプリ起動ショートカット

EXEファイルをドロップするだけでアプリタイルを作成。クリックで任意のアプリを即起動できます。

D&Dで直感的な並べ替え

編集モードに切り替えてタイルをドラッグ＆ドロップするだけで、自由にレイアウトを変更できます。

フォルダもまとめて移動

ファイルだけでなく、フォルダごと移動タイルにドロップして日付フォルダへ一括整理できます。

シンプルな追加・編集・削除

「+」ボタンで追加モード、タイルのクリックで編集ダイアログ。名前やパスの変更・削除が直感的に操作できます。

How to Use

— 使い方 —

1

アプリを起動

DateFiler.exe を起動すると、登録済みのタイルが一覧表示されます。初回は空の状態からスタートします。

2

タイルを追加

右下の「+」ボタンで追加モードに切り替え。フォルダ・アプリをオーバーレイにD&Dして登録します。

3

タイルで整理・起動

移動タイルへファイルをドロップして日付整理、リンク・アプリタイルをクリックして即アクセス。
